# Tool call／正则围栏

两种模式只改变模型如何提出工具请求，共用现有执行器、消息投递和历史数据库。全局设置为 `agent_call_mode=toolcall|fence`。Web 输入框生成选项与 Agent 设置页、Bot `/start` 的工具调用选项、CLI 的同一原生菜单均可修改；不需要部署 Web 才能使用 Bot。

新数据库初始化为 Tool call。已有数据库缺少该设置时初始化为正则围栏；已有值保留。恢复旧应用设置时缺少该项也使用围栏，仅导入对话历史不改变设置。切换影响下一次新请求；同一连续执行、排队接入、等待表单及提交恢复固定原调用模式与提供商／模型。

## 执行与兼容

- OpenAI Chat Completions、OpenAI 兼容接口、Gemini／Vertex、Claude 的非流式、前台和后台流式均接收原生调用。HTTP 地址、API Key、代理、连接池与用量记录继续沿用现有配置。
- 原有 `run-x`、`shell-x`、`stdin-x`、`shellkill-x`、`read-x`、`grep-x`、`intel-x`、`search-x`、`fetch-x`、`edit-x`、`file-x`、Base64 文件写入、`sendfile-x`、`media-x`、`ask-x`、`over-x` 均有对应函数。工具定义里的名字使用 API 允许的 `run_x` 等形式；界面继续显示原协议名。
- Tool call 接收完整参数并按 schema 校验后才执行，同批工具保持顺序。命令、文件内容及编辑旧／新串保留原始空格、缩进和换行。一次响应中所有调用先完成校验，错误或截断参数不执行。
- 每个回合只使用选中的执行入口。Tool call 不执行正文中的围栏；围栏模式不执行原生调用。完成调用按运行、响应、调用 ID 对应结果，重复事件不重执行。
- `ask-x` 仍在 Telegram 内填写或在原浏览器内嵌表单填写。表单后的调用暂停；提交后补齐该调用结果再继续后面的工具。取消后剩余调用记为未执行，交回模型收尾。用户密钥仍只交给现有私密存储，模型取得变量名。
- `over-x` 沿用原有适用范围和成功要求，省略的仅是下一次模型请求。执行事实及调用关系仍保存；包含表单的同批响应不会因提交表单而重新获得免回传资格。
- Agent 开关独立决定是否允许工具。模型明确拒绝 `tools` 等能力时提示手动切换围栏；不自动切换，不把超时、限流当成接口不支持。

`prompts/toolcall_addon.txt` 为可单独编辑的 Tool call 提示词，沿用原版 Agent 的执行规则；原 `agent_addon.txt` 继续用于围栏模式。使用原版围栏提示词时，Tool call 选择对应新文件；用户自定义的 Agent 提示词保留并与当前模式说明一起提供，不自动删改。用户人设和权限不变。

## 历史与展示

工具调用和结果在现有消息元数据中保存，原回复正文仍只有模型实际返回的正文。纯工具响应展示命令卡片，不生成空白正文；工具输出继续独立，Bot 的 50行／3200字符预览、状态点与存档路径保持原规则。最终回复的详情仍只附一次。

同一运行使用目标 API 的原生调用／结果格式；必要的提供商续接字段仅在匹配的提供商、模型和运行中使用。跨运行、切换模型、压缩后的上下文使用明确的历史事实表示，避免没有对应调用的工具结果。原生图片或二进制工具结果完整交回模型；OpenAI Chat Completions 不接受工具消息里的原生附件时，附件作为相邻输入交付。工具留存仍由原有设置控制。

调用参数与结果关联进入历史、导出和分支；读取历史不执行工具。用量沿用接口实际返回值，包括生成工具参数的用量。Tool call 通常仍包含“提出工具请求 → 执行 → 请求模型分析结果”两次模型调用，不承诺固定节省比例。

## 私人仓库与验证

默认仓库及更新源为 `HANLINGVABCN/xgent` 的 `main`。使用已有 GitHub 认证方式克隆；Bot 和安装脚本在线下载读取 `UPDATE_GITHUB_TOKEN`，需要授权本仓库的 Contents 读取权限。明确配置的 `UPDATE_ZIP_URL` 或安装脚本仓库参数仍可覆盖默认源；Token 不写入代码或下载提示。

隔离测试覆盖五种接口与三种生成方式、分片参数、真实调用关系、多工具、表单提交与取消、模式固定、停止、重复调用、无正文、原始文件内容、已有数据库默认值、三端设置和原有围栏。传输模拟只用于验证请求与执行链路，不代表真实模型质量、实际 Token 节省或 Telegram 客户端显示验收。

服务器不部署、不修改、不重启；修改完成后以临时标签运行完整 CI，通过后才发布本私仓 `main`。
