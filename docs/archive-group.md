# 归档分组

归档是隐藏的系统分组，普通分组菜单和首页对话列表不显示它。唯一入口是「设置 → 已归档」：每行提供进入对话、恢复和更多操作。

归档不再让对话只读。进入后可以正常聊天、使用附件、工具和队列；归档期间名称固定，不能新建分支。子对话可以建立，自动归入隐藏归档分组，并在父对话的箭头下面显示。创建子对话时保留归档列表，展开并定位新条目，再点击进入。

列表以父子树展示，展开状态在本浏览器保留。每行显示原分组、原置顶和活动时间。搜索会保留匹配子对话的父链，并展开定位。全局搜索、来源文件或任务链接指向归档列表中的对应行；点击进入后继续使用原聊天记录和来源消息定位。已进入的归档对话可在同一标签页刷新继续。

归档父对话时，其所属子对话一并归档；每个对话单独保存原分组与置顶信息。恢复父对话时子对话一起恢复，随后自动进入父对话。原分组如果已被删除，恢复到默认分组。分支来源关系与子对话所属关系保持独立，不会误恢复另一条分支。

数据库版本 11 增加 `archive_origin` 字段并注册隐藏的保留分组。旧归档数据迁移保留原分组，原来未归档的所属子对话也归入同一归档树。如果原来选中的子对话因此归档，普通列表选中最近的可用对话，Bot 对该子对话的选择同时取消。旧版由归档导致的暂停取消，显式停止、失败、表单等待等状态保留；对话上下文、消息记录、任务执行与模型请求构造沿用原服务。

旧数据库的队列表升级在初始化时重复校验，补齐附件队列字段，避免只在新安装数据库中存在字段。已有待发文本和顺序保持不变。
