# Web 品牌名称与头像

入口为「设置 → 外观」，品牌卡片从「系统名称」直接开始，不显示额外的大标题。默认头像是 4-B 电光赛博霓虹，默认系统名称是 `XGent`。GitHub README 和网页默认图标使用同一份 [Logo](../xgent_app/webui/assets/logo.svg)。

六款预设以 a–f 短标签显示在一条可横向滑动的头像栏中，每个头像下只有一行小字。点击预设后，代码框填入完整 SVG，同时预览左上角、登录窗及 AI 消息头像。所有预设使用相同的 32×32 网格和固定路径，提示符与斜线均为 45°。

点击「自定义」会清空代码框。可以输入 SVG／HTML、HTTP／HTTPS 图片链接或 `data:image/` 图片地址，输入时即时预览。代码框右下角的「保存」将头像加入上方列表；以后可以点击列表里的头像重新使用、查看或修改代码。大头像右侧的「头像名称」配合旁边的「保存」按钮确认名称，也支持按 Enter；修改已有头像沿用原 ID。

「上传本地图片」读取 PNG、JPG、SVG、WebP 等文件为图片 DataURL。上传后可在代码框内保存到头像库；每张图片最多 8 MB，SVG／HTML 最多 65,536 个字符。上传图片在配置里只保存一份，当前头像通过 ID 引用。

系统名称单独填写，点击「保存品牌设置」后生效。代码框内保存头像不会把尚未保存的系统名称一起提交。未保存的预览可取消；保存失败保留输入，原配置不变。恢复默认只恢复当前品牌与默认 4-B，不删除已保存的头像。

名称、当前头像、头像库都保存到 XGent 的 SQLite 配置中，刷新、服务重启和其他网页设备沿用已保存设置；数据库备份与导入包含这些配置。另一设备新增的头像会在保存时合并保留。

这是 Web 显示设置：更新页面标题、登录品牌和 AI 消息署名，不重写对话正文，不修改模型提示词、Bot 或 CLI 人设。SVG／HTML 在隔离的头像区域渲染，脚本和事件处理属性不执行。未登录页面只读取当前品牌与头像，未使用的头像库和业务配置仍需登录才能读取。
