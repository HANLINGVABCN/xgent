# Web 连续命令折叠与停止显示

## 单条命令与输出

网页将 `run-x`、`shell-x`、`stdin-x`、`shellkill-x` 的执行命令与对应结果合并到同一个卡片。顶部显示状态、耗时和命令摘要，点击顶部栏展开或收起整个卡片，收起时命令与输出一起隐藏。展开后，内部“命令”和“输出”是并列折叠区，点击内部命令栏可以只收起长命令正文，继续阅读输出。右侧“查看输出”会展开卡片并打开结果；内部输出栏和右侧按钮均可再次收起输出正文。AI 普通回复里的代码块保持原有显示。

点击命令正文或输出正文也可收起对应的一处正文，内部“命令”“输出”标题仍保留，方便重新展开。拖动选字、双击选词不会触发收起，翻页、复制与下载按钮分别处理自己的操作。

命令代码出现时就建立命令与输出两栏，生成、执行与结束时保留同一卡片。展开外层只显示内部结构，不读取输出；主动点开输出才显示加载转圈并读取结果。命令尚未完成时显示转圈等待，结果保存后只为仍打开的输出读取；期间收起输出或外层便取消等待和读取。减弱动态效果设置下保留静态加载标记。

首次打开输出才读取后台保存的结果，每页最多 64 KiB，按 UTF-8 字节边界分页。翻页替换当前页；当前卡片收起再打开复用已读取的页，不重复获取。保留复制命令、复制完整协议、复制本页、下载完整输出、返回码、终端会话、存档路径与执行说明；执行说明在展开详情后单独分页读取。窄屏按钮自动换行，字节统计不与按钮重叠。失败时卡片保留短错误提示，完整结果仍按需读取。

生成与执行中的停止按钮沿用原运行身份、阶段标识与停止接口，统一放在对应回复的用量与时间信息下方，不嵌入命令正文。命令、输出折叠、流式重绘、结果记录关联和执行中刷新均保留相同位置。合并只改变网页展示与传输：默认历史响应、实时事件队列及重放不携带命令输出正文，数据库原始结果、AI 上下文、执行次数和 Telegram／CLI 的内容保持原有机制。

关联使用原回复记录、调用标识或协议标识，不按命令文字或相邻位置猜测，所以同一轮的重复命令不会串结果。旧历史或分页窗口没有对应命令时，结果以轻量卡片保留入口；若命令记录已经保存对应结果 ID，也可以直接打开输出。读取接口 `/api/workbench/command-output` 校验登录、对话归属、记录受众及撤回状态；存档缺失时明确提示并显示已保存的结果。

## 连续多轮折叠

整次回复结束后，连续至少两轮且正文只有协议命令的 AI 回复组成一个大折叠段。执行中或等待填写表单时不提前折叠；普通正文、用户消息、表单、图片和独立错误消息保持自己的位置。

折叠栏显示该段的 `共执行 N 轮，K 个操作 · 总耗时约 X 秒`。轮数只计入该段纯命令回复；操作根据保存的执行记录关联计数，耗时使用这些轮次的响应耗时与操作耗时，缺少数据时明确显示未记录。多个大折叠分别计数，Web 最后回复的尾注不再重复整次执行汇总。

大折叠收起这段多轮回复中的思考、命令、输出、尾注与轮次行，首条回复的头像和模型留在外面；汇总栏放在该头像下方，与回复正文对齐。点击展开恢复原消息，`Agent 第 N 轮` 仍使用原有全局编号。

展开后的收起按钮位于聊天区域最右侧的空隙，鼠标进入这段展开内容时显示，移到头像、其他回复或输入区时隐藏；从内容移到按钮仍可点击。触屏保留直接点击入口，键盘也能展开与收起。原 DOM、全文、复制和单块展开状态保留，手动展开大折叠的选择在刷新后恢复。Bot、CLI 的原生输出块和最终详情继续使用原有排版。

停止提示独立于正文保存和呈现，按会话、运行身份避免重复显示。原始模型正文、停止标记和报错上下文仍保留，不删除工具报错或错误消息。中间操作失败仍显示原始错误与红点，不再据此生成结尾的失败汇总。

接收回复时停止会把已生成的正文关联到原流式消息，并用刷新同源的数据库视图定稿。临时传输编号只用于同一条记录的接续，不能覆盖另一条已保存的回复；因此服务重启、撤回后的历史重载仍保留撤回范围外的用户消息与 AI 回答。

浏览器回归覆盖桌面、触屏、键盘、明暗主题、实时结束前后、多个独立命令段、头像与模型保留、正文对齐、右侧悬停按钮、文件下载保留、刷新、内部折叠状态以及停止与原始错误同时出现。服务端统计和原始消息仍按原记录保存。
