# 渲染页面与 Telegram Web App

可以要求“做一个图标并展示效果”“把这段 HTML 渲染出来”或“做一个能切换选项的演示页面”。AI 在正常回复中输出 `xgent-html` 或 `xgent-svg` 围栏，标签后可加标题，块内直接写完整自包含源码。它与 Markdown 同属回复格式，不调用工具、不增加 Agent 操作或轮次、不回灌“渲染完成”结果、不为页面追加一次模型请求；Agent 关闭时也能使用。网页直接在隔离 iframe 中渲染，保留回复的前后文字、头像与模型信息，支持内联 CSS、JavaScript、动效和页面内交互。

Telegram 使用普通可展开折叠块显示源码。折叠不减少 Telegram 的字数占用；源码超过单条消息的安全预算时，正文明确写“源码节选 · 完整源码见附件”，同时发送完整 SVG／HTML 文件，不用“已折叠 × 行”替代缺失内容。已启用 Web、配置访问密码和 HTTPS 公开地址时，源码消息附“打开渲染页面”Web App 按钮，沿用现有 Telegram 登录能力，定位同一对话、同一记录并展开同一个网页渲染组件。

完整页面块保存到原 AI 回复的 metadata，原始回复和模型上下文保留完整源码。同一回复最多四块，每块最大 256 KiB；生成时 SVG 图形、HTML 结构和 CSS 随源码逐步渲染，每块围栏闭合后立即独立启用完整脚本和交互，不等待后续页面或整条回复。未完成的脚本和事件处理器在预览中保持静止；生成结束仍未闭合的块保留为普通代码。引用的代码示例、外层围栏中的页面块不创建页面，页面源码里的工具协议也不执行。源码和校验信息关联原消息，刷新可读取；下载按对话与记录授权，撤回、删除或源码变化后旧入口失效。

iframe 使用独立来源沙箱，仅允许脚本运行；宿主 DOM、Cookie、对话状态、网络请求、子框架、外部脚本、CDN 与本地文件不可访问。图片等资源可内联为 data/blob，CSS 和 JavaScript 写在页面源码里。普通页面内交互不自动提交到模型，原有对话构造保持不变。

生成期间先显示带页面标题的预览框和柔和占位动效，已写出的图形和内容随即逐步显示；后续代码在同一预览中更新，保留已有 SVG 节点及 CSS 动画。每块完成后以平滑过渡切换到完整效果。“源码”切换为同一组件中的代码视图，生成期间也实时更新，可复制、单独下载，再切回预览时保留页面内交互状态。已完成的块不会因为后续文字、其他页面或最终保存而重新加载。网页不重复显示 Telegram 的源码附件或 Web App 按钮。

源码视图只追加新收到的文字，不因源码更新重建整条回复。查看源码期间暂缓隐藏预览的解析与绘制，切回预览再合并更新到最新版本；始终处在预览视图时仍保持实时渲染。源码滚动到末尾会跟随新内容，向上阅读或选中文字时保持当前位置；复制读取当前完整源码。尚未渲染的完整脚本会在切回预览时运行，已经完成的交互页面切换源码后保留原状态。浏览器承担渲染工作，服务器继续负责生成、保存与传输。

SVG 优先读取开头的画布尺寸与 viewBox，生成时即可按正确比例建立预览，不等待整块结束。默认以原尺寸的 80% 显示，超过聊天可用宽度或高度时继续等比缩小，图形完整展示；小图不被强制放大到整行。外框贴合画布，只保留工具栏必要空间，图形自身设计的留白保留。HTML 小卡片按内容收紧，长网页保持可读尺寸与内部滚动；只有 SVG 图形的 HTML 包装也按图形适配。浏览器及客户端其余界面不缩放。

预览成果右侧边界中部附着一个竖向窄握柄，带横纹，不使用箭头、不遮挡成果，可将 HTML 或 SVG 整体等比例放大、缩小。拖动仅修改显示缩放，不重建 iframe、不重新执行脚本、不改变页面内部布局。每个对话、回复与页面序号分别在当前浏览器记住手动尺寸，刷新后恢复；屏幕变窄时按可用空间等比限制。标题栏的“恢复自动大小”或双击手柄清除手动尺寸，没有拖动过的页面沿用默认适配。手柄支持触屏拖动与键盘方向键调整，Home 恢复自动。查看源码或展开页面时隐藏手柄，退出后保留原手动大小。源码保留原文，上方工具栏继续使用尖括号和对角箭头图标。

以整个视口为画布、包含 Canvas 或覆盖全屏浮层且禁止内部滚动的 HTML 页面按完整画布适配；开始菜单等居中浮层的实际内容决定最低画布高度，避免只测 body 高度而裁掉标题和按钮。旧手动尺寸若曾记住过矮的画布会补足画布高度，之后拖动仍保持比例和脚本状态；普通长网页继续保留内部滚动。

表达指导集中在 `global_addon.txt`：页面块是正常输出，不是执行或图片发送；普通说明仍用文字。旧版全局默认提示词仅在原文完全匹配时自动备份升级，自定义修改不自动覆盖。网页复用同一组件在对话内和 Web App 展开，服务器无常驻渲染进程，不增加栅格渲染依赖。旧版工具产生的页面记录仍可查看，新的工具清单已移除 render_visual。

聊天输入框左侧边框上的窄纹理握柄可拖动调整输入高度，距输入框顶部保持固定，可压到紧凑的一行；与成果缩放握柄采用相同横纹外观，宽度均为 8px，外侧保留额外拖拽区域。当前浏览器记住手动高度，输入、清空、发送或刷新后保留。双击握柄或聚焦后按 Home 恢复自动高度，方向键上下调整；移动设备和软键盘缩小可用空间时临时限制高度，恢复空间后回到记住的高度，不改变草稿和发送规则。左下方工具按钮采用较小图标并贴近底边。

输入区下方的附件与命令提示行已移除，附件、命令和发送入口继续保留。

思考深度、左侧工具按钮与模型切换共用紧凑的底部对齐高度。模型名称直接显示，不再使用独立背景块与边框，点击仍可切换模型。

手机浏览器弹出键盘时，聊天界面按实际可见区域的高度与上移距离同步调整，输入栏贴着键盘上沿，键盘关闭后恢复；浏览器已缩小布局时不重复扣减键盘高度。调整期间保留输入框节点、草稿和记住的手动高度，缩放浏览器页面不会被误当成键盘弹出。
